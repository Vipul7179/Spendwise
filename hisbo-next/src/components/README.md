# Hisbo Next.js Components Structure

Planned component directories for Phase 3–5:
- `charts/`: SVG chart components (DonutChart, PieChart, BarChart, DailyHistogram)
- `dashboard/`: HeroBalance, DateNavigator, ExpenseList, ExpenseItem
- `blog/`: BlogCard, CategoryFilter, MarkdownView, RelatedPosts
- `modals/`: QuickAddModal, CsvConfirmModal, NameModal, CoffeeModal, DeleteConfirmModal
- `navigation/`: TopBar, MobileNav, MobileDrawer, ThemeToggle, EyeToggle
- `ui/`: Button, Input, Select, Toast, Badge
